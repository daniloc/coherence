# Security Atlas

> Generated by `coherence atlas`. Do not edit by hand — the tiers are derived from the
> `## works when` boundary claims in the `*.spec.md` tree; charts + crossings are `coherence.config.json`.

The security architecture is a **trust-graded manifold**: components are CHARTS (local
trust domains); chokepoints are TRANSITION MAPS that cross between them, re-establishing
the destination chart's invariant. Trust is directional — only an enshrined chokepoint raises it.

## Charts (trust domains)

| chart | description |
| --- | --- |
| `project-source` | The repository under analysis as it is on disk: *.spec.md prose, source text, coherence.config.json, git history. Agent-authored and arbitrary — never trusted as a statement about itself, only as text to be read. |
| `derived-model` | The graph the harness builds from that text — components, claims, symbols, import edges — plus the config it was walked with. Everything downstream is computed over this and nothing re-reads the tree. |
| `shell` | The other side of a process boundary: the commands the harness spawns for evidence (test runner, typecheck, project `measures` probes) and the hook process the agent harness spawns to reach the journal. Nothing here is the harness's own memory, and an exit code is the only fact that crosses. |
| `record` | The durable memory a LATER run compares against — .coherence/status.json, the pinned baselines in public/, the decision journal. Every ratchet in this repo is a comparison against this chart, which is why a byte of garbage in it is a gate that went quiet. |
| `verdict` | What a gate is permitted to SAY: a claim's green/red/skip, a ratchet's held/failed, the process exit code. The scarcest chart in the system — a fact reaches it only through a crossing that earned it. |
| `reading-surface` | What a human or an agent then reads: public/_*.html, AGENTS.md, CLAUDE.md, the terminal reports. Derived text with no authority of its own; it can mislead, but it cannot turn a red green. |

### Headline — tier-3 security crossings (unmanaged)

- `buildGraph` (`project-source` → `derived-model`) — The single ingress: arbitrary repository text becomes the model every downstream gate is computed over.
